\# Final Directive — AI Job Application Copilot



\## Mission



Build a working tool that helps job seekers compare their resumes with job descriptions, understand relevant skill matches and potential gaps, and generate professional application messages.



\## Core requirements



1\. Accept resume text and a job description.

2\. Identify skills detected in both inputs.

3\. Report potential gaps without claiming the candidate lacks those skills.

4\. Generate a professional, role-specific application message.

5\. Validate user inputs and handle invalid requests safely.

6\. Provide automated tests and clear setup instructions.



\## Working principles



\- Use AI as a collaborative development partner for planning, coding, debugging, testing, and documentation.

\- Inspect and test generated code instead of accepting it blindly.

\- Prefer small, verifiable changes over large untested changes.

\- Use evidence from tests and examples to decide whether an improvement works.

\- Record important prompts, decisions, failed approaches, and corrections in the AI usage log.

\- Never invent a candidate's qualifications or claim that an undetected skill is definitely absent.

\- Keep the solution understandable, reproducible, and suitable for demonstration.



\## Definition of done



The application runs locally, its API endpoints work, automated tests pass, documentation explains how to run it, and the repository can be reviewed by another developer.



The final submission must also include a truthful account of the problem, assumptions that changed, AI-assisted decisions, and limitations discovered during development.
